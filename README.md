# Retro Project Directory

A browser-based interactive project directory built with HTML, CSS, and JavaScript. This site displays project cards, individual project pages, image galleries, and playful retro-inspired interface elements.

## Description

This website is both a project and a platform for showcasing other projects. It was created as an interactive directory where visitors can browse project files, view details, explore images, and interact with fun Y2K-style web features.

The design is inspired by old desktop interfaces, early internet graphics, CRT displays, and retro web aesthetics.

## Features

- Dynamic project cards generated from JavaScript data
- Individual project detail pages
- Project title, category, people, summary, tools/materials, and description sections
- Clickable image lightbox for larger image previews
- Scrollable About section for longer descriptions
- Animated marquee banner
- Random project button
- Sparkle cursor effect
- Interactive stickers
- Fake loading widget
- Fake system error screen
- VHS-style project transition
- Auto-return to the directory after inactivity on project pages
